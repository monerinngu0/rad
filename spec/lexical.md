# Lexical conventions

Status: Draft.

## Currently agreed

- Identifiers name bound values, functions and members.
- Whitespace separates tokens except where punctuation already separates them.
- The language will support comments.
- The exact comment syntax is not yet normative.

## To decide

- Exact identifier grammar.
- Integer literal spelling.
- Whether numeric separators are supported.
- Comment syntax.
- Whether newlines are significant outside `print:`.
- Reserved words. Current likely reserved words include `print` and `each`.
